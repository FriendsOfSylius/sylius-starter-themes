# sylius-starter/themes

Ready-to-use Sylius storefront themes (Canvas, Blush, Prompt Dark, Prompt Light, Volt, Lagoon, Aurora, Tech, Retro Gaming, Drive, Cellar): `sylius:theme:setup`. Custom themes can be declared with the `#[AsThemeInstaller]` and `#[AsThemeRemover]` attributes. It also adds a theme question to `castor docker:service:install sylius`.

## Installation

In your Castor project:

```bash
castor composer require sylius-starter/themes
```

Or install every Sylius Starter package at once with `sylius-starter/sylius-starter`.

Read the [documentation](https://github.com/sylius-starter/sylius-starter/blob/main/docs/commands/themes.md) for usage.
